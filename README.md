# مساعد ذكي للبيئة الصفية — Smart Classroom Assistant

منصة ويب تفاعلية مدعومة بالذكاء الاصطناعي لمعلمات رياض الأطفال في المملكة العربية السعودية. تساند المعلمة أثناء الدرس: تطرح الأسئلة على الأطفال صوتياً، وتستمع لإجاباتهم وترد عليها، وتسرد القصص، وتنظم أدوار الحديث، بينما تبقى المعلمة صاحبة القرار والتحكم الكامل في الجلسة.

> **الحالة:** قيد التطوير — المرحلة 0 (التحليل والخطة) مكتملة، والمرحلة 1 (قاعدة البيانات) لم تبدأ بعد. لا يوجد كود تشغيلي في المستودع حتى الآن.

## لماذا هذا المشروع

في استبيان ميداني شاركت فيه 51 معلمة رياض أطفال، أفادت 44 منهن بصعوبة في المحافظة على انتباه الأطفال أثناء الشرح، وأغلب الفصول تضم بين 16 و30 طفلاً. المعلمة تدير المحتوى والتفاعل وضبط الفصل في الوقت نفسه، وتجمع المحتوى من مصادر متفرقة. المنصة تخفف عنها جزءاً من عبء إدارة التفاعل وإعداد المحتوى، ولا تحل محلها.

## ما تقدمه المنصة

| الجانب | الوصف |
| --- | --- |
| إعداد الدروس | إنشاء درس وأنشطته (قصة، حوار أسئلة، نشاط تفاعلي)، وحفظه وإعادة استخدامه |
| تجهيز المحتوى بالذكاء | اقتراح قصص وأسئلة وأنشطة مناسبة للعمر، ولا يُعرض شيء على الأطفال قبل اعتماد المعلمة |
| التفاعل الصوتي | أسئلة وإجابات صوتية بالعربية مع فهم اللهجة السعودية، وتبسيط السؤال عند الحاجة |
| القصص التفاعلية | سرد يمكن مقاطعته بسؤال من طفل ثم العودة لنفس النقطة |
| إدارة التفاعل | إجابة مختصرة عن الأسئلة الخارجة عن الموضوع ثم العودة للدرس، وتنبيه المعلمة عند الحاجة |
| الجدول اليومي | جدولة الأنشطة مع تنبيهات عند بدايتها ونهايتها، دون بدء أي نشاط تلقائياً |
| تحكم المعلمة | بدء الجلسة وإيقافها، والتنقل بين الأنشطة، وإيقاف المساعد بأمر واحد في أي لحظة |
| الواجهة المادية | روبوت من الكرتون والجوخ يوضع داخله الجهاز، أو العرض على شاشة الفصل |

الفئة المستهدفة: أطفال من 3 إلى 6 سنوات.

## التقنيات

| الطبقة | التقنية |
| --- | --- |
| الواجهة الأمامية | React + Vite |
| الخادم | Python + FastAPI |
| قاعدة البيانات والدخول | Supabase (PostgreSQL + Supabase Auth) |
| الصوت والذكاء الاصطناعي | خدمات STT وTTS وLLM خارجية خلف طبقة وساطة قابلة للاستبدال — المزودون يُحددون بعد اختبار أولي |

المتصفح يتواصل مع الخادم فقط، والخادم وحده يتصل بقاعدة البيانات والخدمات الخارجية، فلا تصل مفاتيح الخدمات إلى المتصفح.

## الخصوصية — قواعد غير قابلة للتفاوض

- **لا تُحفظ أصوات الأطفال** في قاعدة البيانات أو أي ملف. الصوت يُحوَّل إلى نص لحظياً ثم يُرمى.
- **لا توجد بيانات تعريفية للأطفال**: لا أسماء ولا صور ولا ملفات فردية ولا تقييم أداء.
- **عزل بيانات كل معلمة** عن غيرها على مستوى الخادم وقاعدة البيانات.
- لا يُرفع إلى المستودع أي ملف `.env` أو مفتاح أو تسجيل صوتي (يضمن ذلك ملف `.gitignore`).
